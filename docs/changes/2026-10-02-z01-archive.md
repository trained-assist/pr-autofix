## Корневая причина R1

Предикат `-d "$target/.git"` → «есть `.git` = наш остаточный клон» (решение #63). Контракт S1/S4 защищал только consumer, владение целью не специфицировано. `rm -rf` чужой цели — прямое следствие. Дифференциальный эксперимент `iter7/root-cause-differential.sh`: без `.git` → отказ, чужой git checkout → exit 0. Решающая переменная — наличие `.git`, не принадлежность.

## Почему не поймали

Прежняя регрессия проверяла только чужой каталог без `.git`; оракул ассертит `.git = ours` зелёным; классовый скан грейдит форму YAML, не предикат; в репо не было ни одной пробы на чужой git checkout.

## Грабли

1. Одинаковый guard стоит в 4 файлах — дрейф копий = красный билд в CI (класс-скан).
2. Локальный PASS и remote tree не заменяют hosted evidence (R2 вердикт итерации 6).
3. `git/trees/HEAD` не доказывает сохранность untracked или отсутствие лишних staged путей в рабочем каталоге runner.
4. Формулировки о проде/выпуске — не расширять текущий scope на rollout.
5. Пин `v1.7.9` (`41b9933`) дефектен — установщик падает на ref, где cleanup-workflow не callable. Живой дефект не исполнился (ни один потребитель org не стоит на окне).
